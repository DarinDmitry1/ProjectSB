# ProjectSB
Описание проекта

ProjectSB — это консольная игра, реализующая классический режим «Морского боя» с добавлением новых механик:

 мины, наносящие ответный урон;

авиаудар по выбранной области;

возможность играть против другого игрока или искусственного интеллекта.

Проект выполнен в рамках учебной дисциплины «Проектная практика» и демонстрирует основы объектно-ориентированного программирования на языке C++.

Основные возможности

Автоматическая расстановка кораблей и мин
Поддержка двух режимов игры: человек–человек и человек–ИИ
Возможность выполнения авиаудара один раз за игру
Обработка некорректного пользовательского ввода
Отображение игрового поля и состояния игры в консоли
Разделение кода на модули (Board, Player, Ship)

Установка и запуск
Требования

Компилятор C++17 или выше

Среда разработки (например: CLion, Visual Studio, Code::Blocks, g++)

Поддержка стандартной библиотеки STL

Запуск

Склонируйте или скачайте проект:

git clone https://github.com/DarinDmitry1/ProjectSB.git


Откройте проект в IDE или в консоли.

Скомпилируйте код:

g++ main.cpp Board.cpp Player.cpp Ship.cpp -o ProjectSB


Запустите игру:

./ProjectSB

Игровой процесс

При запуске игрок выбирает режим:
1 — Игра против ИИ
2 — Игра вдвоём

Игроки делают выстрелы, вводя координаты X Y.

Команда F активирует авиаудар (один раз за игру).

При попадании по мине происходит взрыв, и игрок получает ответный урон.

Победа достигается, когда все корабли противника уничтожены.

Искусственный интеллект

ИИ выбирает случайные координаты для выстрелов, избегая повторных атак по уже поражённым клеткам.
В будущем возможна реализация “умного” ИИ, анализирующего попадания.
